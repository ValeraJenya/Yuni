### Счётчик `oklch(...)`: 29 → 4

25 из 29 литералов переведены на классы Tailwind (токены Task 085 или уже
существующие shadcn/brand-токены). Разбивка:

- **6 точных совпадений с уже существующими токенами** (не новыми):
  `--input`, `--muted` (×2), `--carbon` (×2), `--primary` (×через alpha-модификатор, несколько вхождений).
- **19 — ближайший токен шкалы Task 085** (`--surface-*`/`--text-*`),
  ΔL от 0.000 до 0.042 — весь диапазон меньше сдвигов, уже одобренных
  при утверждении шкалы.

**4 литерала (3 уникальных значения) остаются как есть — решение
владельца, не моё:**

| Литерал | Где | Причина |
|---|---|---|
| `oklch(0.70 0.22 18)` | цвет иконки в бейдже строки | ближайший по оттенку — `--ruby`, но разрыв по светлоте 0.22 — заметно больше любого одобренного в Task 085 сдвига |
| `oklch(0.78 0.16 28)` ×2 | текст `actionError` и бейдж «Новое» | семья `--warning`, но разрыв по L 0.08; **у семьи 28 три реальных уровня (0.70×5 в discover, 0.78×2 в notifications, 0.62×1), токен один** — подгонять именно в пилоте нельзя, это смазало бы измерение цены |
| `oklch(0.62 0.22 28 / 0.18)` | бордер `actionError` | та же причина |

**Находка для Task 087: семье `--warning` нужен второй уровень**
(например, `--warning`/`--warning-strong` или похожая пара) — не
находка этого пилота специально, а прямое следствие того, что здесь её
не стали подгонять молча.

### Обнаруженные при миграции ловушки (входные данные для Task 087)

Обе — не про эту задачу конкретно, но встретятся на каждом следующем
экране, если не знать о них заранее:

1. **`dark:`-варианты компонентов перебивают токен-классы.** `Button`
   `variant="outline"` содержит `dark:bg-input/30 dark:border-input
   dark:hover:bg-input/50`. Приложение всегда в тёмной теме
   (`<html class="dark">`), поэтому эти классы всегда активны.
   `tailwind-merge` не считает `bg-muted` (без модификатора) и
   `dark:bg-input/30` конфликтующими — оба остаются в выводе, и
   `dark:`-вариант выигрывает каскадом. Без явного `dark:bg-muted
   dark:border-primary/22 dark:hover:bg-muted` кнопка «Прочитать все»
   рендерилась с `bg-input` на 30% прозрачности вместо непрозрачного
   `--muted` — проверено через `getComputedStyle`, не разница, а
   реальная ошибка. Пойман и исправлен здесь; при 087 писать `dark:`-пару
   для каждого утилити-класса, которым перебивается `dark:`-вариант
   компонента.
2. **`Empty` не даёт border-width.** Базовый класс — `border-dashed`
   (только стиль), без `border` (ширина). Без явного `border` в
   `className` бордер невидим (`border-width: 0px`, подтверждено
   computed style). Тоже пойман и исправлен здесь.

## 3. Отчёт о визуальных различиях

Каждое — с вердиктом, не растворено в диффе.

| Что изменилось | Почему | Вердикт |
|---|---|---|
| Кнопки «Прочитать все»/«Загрузить ещё»: появился `hover`-эффект (смена `bg`/`text` при наведении) | `Button variant="outline"` по умолчанию даёт `hover:bg-accent`; переопределён обратно на `hover:bg-muted`/`hover:bg-surface-2` (тот же цвет, без смены), чтобы **не** добавлять новое поведение в задаче о цвете | приемлемо — поведение сохранено, не добавлено |
| Высота кнопок: `h-8` (32px) вместо неявной (`py-2`+`text-12px`, ~34-36px) | `Button size="sm"` — стандартная ступень, точной прежней высоты не было и в оригинале (не задавалась явно) | приемлемо |
| `Empty`-блок пустого состояния: бордер `dashed`, а не `solid` | `Empty` — базовый класс компонента, собственная визуальная идентичность shadcn для «пусто» | приемлемо — это то, ради чего берут именно этот компонент, не борьба с ним |
| `Empty`-блок: паддинг `p-6 md:p-12` вместо прежнего `px-6` (без явного вертикального) | базовые классы `Empty` | приемлемо, минимальная разница на пустом экране |
| Подзаголовок строки уведомления: `line-clamp-1` вместо `truncate` | `ItemDescription` по умолчанию даёт `line-clamp-2`; переопределено на `line-clamp-1`, а не `truncate`, чтобы остаться в одной utility-группе и не столкнуться с конфликтом `display` (line-clamp использует `-webkit-box`, `truncate` — `overflow`/`text-overflow`, смешивать рискованно) | приемлемо — видимый результат (одна строка, многоточие) идентичен |
| Отступ между заголовком строки и подзаголовком: `gap-0`+`mt-1` вместо изначального неявного (только `mt-1` на подзаголовке) | `ItemContent` по умолчанию даёт `gap-1` между детьми; переопределено на `gap-0`, сохранён явный `mt-1` на описании — совпадает с прежним визуальным расстоянием | приемлемо |
| Литералы `--ruby`-по-оттенку (иконка) и `--warning`-по-оттенку (текст/бордер `actionError`, бейдж) остаются `oklch(...)` литералами | разрыв по светлоте больше одобренного диапазона (иконка) или решение не подгонять семью из трёх уровней под один токен в пилоте (warning) | приемлемо для пилота — явно выписано выше, решение по семье `warning` — за Task 087 |
| Контраст двух пар из Task 089 (см. раздел 4) чуть снизился | ближайшие токены на 0.013–0.015 темнее исходных литералов | **не приемлемо молчать** — см. раздел 4, чинить не в этой задаче, но зафиксировано явно |

Всё остальное — 1:1 та же разметка, тот же порядок классов
компоновки (`flex`, `gap`, `rounded-*`), только цвет ушёл с
`style={{}}` на `className`.
