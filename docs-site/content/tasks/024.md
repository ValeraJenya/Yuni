## Описание

`endActiveMatchesBetween()` теперь атомарно закрывает и `Match`, и связанный `Conversation` в одной транзакции с созданием `Block`.

## Что реализовано

- `blockUser()` в транзакции создаёт `Block` и переводит `Match.status` в `blocked` (PR #31).
- `endActiveMatchesBetween()` дополнительно переводит `Conversation.status` из `active` в `closed` для матчей между теми же двумя пользователями, в той же транзакции.
- `findWritableConversationOrThrow()` уже отклоняет отправку сообщений при `status !== active` — с этим изменением проверка начинает реально срабатывать при блокировке.
- Как и `Match` (который не возвращается в `active` при unblock), `Conversation` остаётся `closed` навсегда — `unblockUser()` намеренно не переоткрывает переписку.
- Тесты: `moderation.service.spec.ts` — обновлены happy-path проверки на `blockUser`/duplicate-block пути + новый тест на откат при сбое `conversation.updateMany`.
