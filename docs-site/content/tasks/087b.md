## Что изменено

Файл: `apps/frontend/app/(app)/matches/page.tsx`.

- Использованы `Alert`/`AlertDescription`, `Badge`, `Button`, `Empty`/`EmptyHeader`/`EmptyMedia`/`EmptyTitle`/`EmptyDescription` из `components/ui` там, где они подходят без изменения визуального языка экрана.
- `onMouseEnter`/`onMouseLeave` на карточке матча удалены: border/shadow hover и focus-within теперь заданы CSS-классами. Это закрывает единственное `onMouseEnter` в `/matches`, найденное в Task 092 inventory.
- `oklch(` на экране: **64 → 4**. Большинство значений переведены на tokens/`color-mix(in oklab, var(--token), transparent)`.
- Оставшиеся 4 литерала осознанные: hue-25 для error/destructive более светлого уровня и hue-145 для success-сообщения. Для этих семей сейчас есть один token-level, а на экране реально нужны разные видимые уровни; молча подгонять их под один токен нельзя.
