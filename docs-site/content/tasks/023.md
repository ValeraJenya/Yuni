## Описание

EXIF stripping, image sanitization, pending/private lifecycle. Реализовать безопасную обработку загружаемых изображений: удаление EXIF-метаданных, валидацию сигнатуры файла, жизненный цикл фото (pending → approved/rejected). PR #23 уже создал storage boundary как основу.

Blind audit дополнительно подтвердил, что при delete DB row удаляется раньше физического файла, storage error подавляется, а static serving не сверяется с БД. Этот отдельный deletion-consistency finding вынесен в Task 047 и должен учитываться при проектировании media lifecycle.
