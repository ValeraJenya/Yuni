## Статус

`done` · P1

## Связь

Извлечено из Task 027.

## Finding

Таблица `conversation_starters` создаётся миграцией, но seed/`INSERT`/`createMany` отсутствуют. На чистой БД `GET /chat/starters` возвращает `[]`.

## Scope

Добавить идемпотентный, воспроизводимый seed/catalog lifecycle и определить ownership локализации/редактирования фраз.

## Acceptance

- migrate/seed clean database даёт ожидаемый starter catalog;
- повторный seed не создаёт дубликаты;
- endpoint возвращает 3–4 активные фразы;
- clean-DB scenario покрыт test.

## Что сделано

Закрыто вместе с Task 072: `seedConversationStarters` в `apps/backend/prisma/seed/starters.ts` наполняет `conversation_starters` четырьмя активными фразами при запуске `pnpm --dir apps/backend prisma:seed`. Идемпотентно (existence-check по тексту фразы перед вставкой, апдейт `isActive: true` при повторном запуске вместо дубля). Проверено вручную: на чистой базе `GET /chat/starters` возвращает 4 фразы; повторный запуск сида не меняет количество строк в `conversation_starters`.

Отдельный test для этого сценария не добавлен — задача решена как часть демо-сида, а не как отдельный production-путь заполнения каталога; e2e-сьют (`yuni_test`) не подпадает под сид намеренно (см. guard в Task 072), так что этот путь остаётся непокрытым тестами до тех пор, пока каталог фраз не станет production-функциональностью с собственным lifecycle.

## Evidence

Влито в `main`: PR #77 / merge `8feff3b`, коммит `08baab0`. Тело коммита
называет закрытие Task 045 явно: «`conversation_starters` заполнена 4
активными фразами — закрывает Task 045 (`GET /chat/starters` больше не
возвращает `[]` на чистой базе)».

Проверка — ручная, на scratch-базе `yuni_demo`; автоматического теста на этот
сценарий в репозитории нет.

## Осталось за рамками

Пункт acceptance «clean-DB scenario покрыт test» не выполнен и закрыт не был.
E2E-сьют работает против базы `yuni_test`, которую guard сида намеренно
отказывается заполнять (см. Task 072), поэтому путь остаётся непокрытым
тестами до тех пор, пока каталог фраз не станет production-функциональностью
с собственным lifecycle, а не частью демо-сида.
