## Статус

`idea` · P1

## Finding

Landing утверждает manual profile verification и 24/7 moderation. Фактически email verification отсутствует, а profile photos автоматически получают `approved` без очереди проверки.

## Scope

До реализации Tasks 023/033 привести публичные claims к фактам либо реализовать обещанный процесс с измеримыми guarantees. Не использовать security theatre.

## Acceptance

- публичные тексты соответствуют runtime behavior;
- будущие claims имеют owner, процесс и evidence;
- проверена согласованность landing/auth/help docs.
