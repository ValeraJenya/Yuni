## Статус

`idea` · P2

## Связь

Узкий follow-up Task 027 после синхронизации API/security docs.

## Finding

Frontend `ChatMessage.senderUserId` объявлен обязательным `string`, но backend system transition messages возвращают `null`. Автоматических contract tests между backend staged responses и frontend DTO нет, поэтому поля снова могут разойтись.

## Scope

Согласовать nullable sender и staged response types (`stage`, `voiceLimits`, game/starters, `voiceDurationSec`, `messageWeight`, `isSystemMessage`) и добавить machine-checked contract boundary.

## Acceptance

- system messages типизируются с `senderUserId: string | null`;
- frontend DTO покрывает текущие staged responses;
- contract test падает при несовместимом backend/frontend drift.
