## Статус

`idea` · P1

## Finding

Google и Apple controls на auth UI декоративны: handlers, provider configuration и backend OAuth flow отсутствуют.

## Scope

Либо реализовать полный OAuth lifecycle с state/nonce, account linking и безопасным callback, либо убрать/явно отключить controls до готовности.

## Acceptance

- видимые controls не создают ложного успешного affordance;
- при реализации проверяются state/nonce и trusted redirect URIs;
- account-linking collisions покрыты tests.
