## Статус

`done` · P2 — PR #73 / merge `90fe38a`

## Finding

`/hero-portrait.jpg` — фотография модели с лендинга — используется как заглушка аватара в шести местах: `profile/page.tsx:164`, `discover/page.tsx:569` и `:1127`, `messages/page.tsx:65`, `discovery-api.ts:38`, `mock-data/profiles.ts`.

Лицо конкретного человека становится аватаром любого пользователя без фотографии, включая самого себя в собственном профиле.

## Acceptance

- ни один экран не показывает `/hero-portrait.jpg` как аватар;
- заглушка выбирается по полю `gender`, для незаполненного пола есть нейтральный вариант;
- ассеты векторные и используют токены из `globals.css`;
- читаются в реальных размерах аватара (от 40px).

## Источник

Ручная проверка сервиса владельцем 2026-08-14.

## Что сделано

Закрыта в PR #73 / merge `90fe38a`.

`defaultAvatarUrl(gender, variant)` в `apps/frontend/lib/default-avatar.ts`.
Два варианта на каждый пол: `card` — ростовой портрет 4:5 для крупных карточек
Discovery и профиля, `square` — кроп по плечи для маленьких круглых аватаров в
списках, где от ростовой фигуры остаётся тёмное пятно.

`defaultAvatarUrl` нормализует пол сам и не полагается на конкретный набор
значений: поле в схеме — свободная строка (Task 035). Всё нераспознанное,
включая пустое значение и небинарные варианты, получает нейтральный силуэт, а
не портрет наугад.

Заодно локализована подпись «Ты» в оверлее матча — она была жёстко на русском.

`pnpm --filter frontend lint` — 0 ошибок, 17 предупреждений; `tsc --noEmit`

## Отклонения от acceptance

- **Ассеты не векторные.** Acceptance требовал векторных ассетов; по факту
  гендерные варианты — растровые WebP (16 и 24 КБ ростовые, 8 и 12 КБ
  квадратные, из исходных PNG по 1.5 МБ). Векторный только нейтральный
  вариант — SVG на 334 байта. Иллюстрации предоставлены владельцем, решение
  принято осознанно.
- **Два места намеренно получают нейтральную заглушку вместо гендерной:**
  список диалогов (chat API не отдаёт пол собеседника в
  `ChatParticipantSummary`) и аватар «Ты» в оверлее матча (`useAuth` отдаёт
  только handle и displayName). Показывать там портрет наугад было бы хуже,
  чем силуэт. Чтобы заменить его на настоящую заглушку, нужно расширить
  сериализаторы — отдельная задача.
