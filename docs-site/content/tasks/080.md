## Статус

`review` · P3 — ветка `fix/task-079-public-console` (отдельный
коммит от Task 079).

## Finding

`apps/frontend/app/(app)/messages/page.tsx:329` — `<input>` поля поиска по
диалогам без атрибутов `id`/`name`. Консольный issue:
`A form field element should have an id or name attribute`.

## Acceptance

- у инпута появляются `id` и `name`;
- никакие другие поля форм не тронуты (autocomplete на `/join`/`/signin` —
  отдельная Task 081).

## Источник

Подтверждено дважды независимо: инвентаризацией 2026-08-20 и визуальной
проверкой Task 048.

## Решение

Добавлены `id="messages-search"` и `name="messages-search"` на
существующий `<input>`. Одна строка, без изменения поведения или вёрстки.

## Evidence

Через `Claude_Browser`, залогиненная сессия, `/messages`:
`document.querySelector('input[placeholder="Поиск..."]')` →
`{id: "messages-search", name: "messages-search"}`. Консольный issue про
отсутствующий `id`/`name` для этого поля исчез.

`pnpm --filter frontend lint`/`test`/`tsc --noEmit`/`next build` — см.
общую evidence в `docs-site/content/tasks/079.md` (один прогон на обе
задачи, один PR).
