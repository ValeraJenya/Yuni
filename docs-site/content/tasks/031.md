## Статус

`idea` · P1

## Finding

Forgot-password UI имитирует успешную отправку через `setTimeout`. Backend endpoint, одноразовый token lifecycle и фактическая смена пароля отсутствуют.

## Scope

Спроектировать безопасные request/confirm endpoints, expiring single-use tokens, neutral anti-enumeration responses, rate limits и delivery boundary. Заменить mock UI реальной интеграцией.

## Acceptance

- запрос не раскрывает существование email;
- token ограничен сроком/одним использованием и хранится безопасно;
- успешный reset инвалидирует нужные sessions;
- критический flow покрыт integration tests.
