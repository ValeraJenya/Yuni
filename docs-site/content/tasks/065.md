## Статус

`review` · P2

## Связь

Task 025 описывает будущую production architecture. Task 065 фиксирует текущий отдельный gap: delivery automation приложения отсутствует.

## Finding

В `.github/workflows/` есть quality gates и deployment Hugo docs-site. Для backend/frontend нет build/publish Docker images и deploy ни в одно application environment.

## Scope

После архитектурных решений Task 025 добавить минимальный repeatable application build/publish/deploy flow с environment protection и rollback.

## Acceptance

- backend/frontend artifacts воспроизводимо собираются и публикуются;
- secrets не имеют insecure defaults;
- deploy target, approvals, migrations и rollback определены;
- docs-only Hugo pipeline остаётся отдельным.

## Реализация

Добавлен `.github/workflows/application-images.yml`: workflow на `push` в `main`, tags `v*` и `workflow_dispatch` собирает backend/frontend Docker images и публикует их в GitHub Container Registry. Деплой в staging/prod не добавлялся; docs-site Pages workflow остался отдельным.

Evidence: изменения подготовлены в ветке `codex/task-065-app-cd-pipeline`; фактические проверки фиксируются в отчёте задачи.
