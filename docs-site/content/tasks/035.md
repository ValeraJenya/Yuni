## Статус

`idea` · P1

## Finding

`gender` и `lookingFor` хранятся как свободный текст, тогда как frontend ведёт себя как consumer фиксированного enum-like набора. Это допускает произвольные и несовместимые значения.

## Scope

Согласовать продуктовый набор, nullable/unknown semantics, backfill и миграцию; затем синхронизировать Prisma, validation, API и frontend selects.

## Acceptance

- canonical values и compatibility policy утверждены;
- existing data безопасно backfill-нута;
- DB/API/frontend отклоняют неканонические новые значения;
- публичный контракт документирован.
