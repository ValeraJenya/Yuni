## Статус

`idea` · P0

## Finding

Privacy и notification settings представлены в UI, но для них нет целостного backend API/persistence contract. Пользователь может считать, что настройка применена, хотя server state не меняется.

## Scope

Определить authoritative settings model, GET/PATCH endpoints, defaults, authorization и фактическое применение к Discovery/notifications.

## Acceptance

- UI загружает и сохраняет server state;
- privacy gates применяются на backend, а не только визуально;
- notification producers учитывают preferences;
- defaults/migrations и end-to-end scenarios документированы.
