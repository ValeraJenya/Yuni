## Описание

Только страница профиля применяет `resolveProfilePhotoUrl()`. Discovery, matches и messages используют относительный `/uploads/...` URL напрямую — браузер обращается к origin фронтенда, а не бэкенда.

Нужно ввести единый контракт resolution backend media URLs для всех frontend consumers и покрыть его tests. Выбор между абсолютным URL в API и общим frontend resolver должен быть зафиксирован до реализации.
