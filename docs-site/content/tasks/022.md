## Описание

Подтверждённый finding: profile page преобразует относительные `/uploads/...` через frontend base URL helper, а Discovery, matches и messages используют полученный URL как есть. При раздельных frontend/backend origins фотографии в этих трёх flows ломаются.

Нужно ввести один контракт resolution backend media URLs для всех frontend consumers и покрыть его tests. Выбор между абсолютным URL в API и общим frontend resolver должен быть зафиксирован до реализации.
